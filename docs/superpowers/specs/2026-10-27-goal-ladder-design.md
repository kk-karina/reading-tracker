# Лесенка целей с призами — дизайн

Дата: 2026-10-27. Статус: реализовано. Расхождения с первой редакцией:

- Картинки лежат в `src/assets/stickers/*.webp` (256px) и собираются
  `import.meta.glob` в `src/lib/learning/stickers.ts` — как аватары, а не из
  `public`.
- «Добавить шаг» открывает строку-черновик: шаг заводится, только когда в
  ней что-то написано (Enter или уход из поля), и фокус переходит в поле
  приза. Пустых шагов в базе не остаётся. Пустой поток открывает лист с
  такой строкой.
- «Не сделано» стоит под купоном, а не рядом с крестиком: в строке ссылка
  отнимала у купона ширину.
- Ручка перестановки — значок `move` из набора; перестановка — `y` у
  `motion.li` и `layout="position"`.
- Таймлайн: пока шаги влезают, у пути нет прокрутки вовсе (`overflow:
  visible`), иначе отгиб при жесте обрезался бы; у закрытых стикеров нет
  пустого отражённого слоя. Ширина ячейки — 128px, на узком экране 100px.
- В листе на узком экране купон вертикальный, как в празднике.
- «Все шаги позади» — без числа: склонение «N шагов» ради одной строки не
  окупалось.

У потока в обучении есть одна большая цель — мотивирующая фраза в шапке
(`StreamGoal`). Она — north star и остаётся. Но до неё далеко, и по дороге
ничего не радует. Спека заводит **лесенку шагов**: цель разбивается на
шаги («сдать теорию → записаться на практику → … → сдать вождение»), к
каждому шагу Карина сама привязывает приз («поход в Черноморку»), и когда
шаг сделан, приложение празднует и объявляет приз. Последний шаг — главный
приз.

Эталон вида и поведения — живой макет
`.superpowers/brainstorm/99743-1793128857/content/album-v14.html` в корне
`Reading tracker` (открывать через сервер компаньона или любым статическим
сервером из папки `content`, картинки лежат рядом как `st-*.png`). Всё, что
ниже описано словами, в нём можно потрогать. Где спека и макет расходятся —
права спека.

## 1. Зачем и что считается успехом

- Большая цель распадается на ступеньки, и у каждой своя награда — радость
  приходит по дороге, а не только в конце.
- Закрыть шаг — маленький ритуал, а не галочка: стикер отклеивают, как
  настоящий, и экран празднует.
- Призы — сюрпризы с намёком: видно, что под стикером что-то есть, но не что
  именно (хотя придумала их сама Карина).
- Геймификация вторична. Главное на экране потока по-прежнему фокус — то,
  что изучаешь сейчас.

**Не цели.**

- Учёт, сходила ли она за призом. «Это на мне» — приложение только объявляет
  приз в момент победы.
- Лесенка в разделе чтения. Хочется и там, но это следующий проект; здесь
  решения принимаются так, чтобы компоненты переехали без переделки (§10).
- Загрузка своих картинок. Картинки — только из зашитого набора (§7).
- Очки, уровни, серии за шаги — ничего, кроме шагов и призов.

**Анти-цели — провал, даже если работает.**

- Шапка потока меняется. Она остаётся ровно такой, как сейчас: фраза,
  «Записать занятие», фокус, «Ещё изучаю».
- Мерцание при переходах (см. память о переходах: содержимое подменяется в
  кадре, без `key` по адресу и без гашения страницы).
- Второй способ сделать то, что в проекте уже решено: своя кнопка закрытия
  листа, своя форма вместо правки по строкам, свой переключатель вместо
  `Segmented`. Правила — в `CLAUDE.md` («Сначала ищи готовый паттерн», «Лист:
  закрыть и сохранить»).
- Стикеры с разной каёмкой в разных местах (§6.1 — одна анатомия).

Блок шагов стоит в `StreamDashboard` **над** `.stream-hero`, отдельным
блоком. Он светлый (бумага), тёмная подложка потока остаётся главным
предметом экрана. Кнопка «Записать занятие» живёт в подложке, при фокусе —
к шагам она не относится.

## 3. Данные — миграция 010

```sql
create table if not exists public.stream_steps (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null default auth.uid() references auth.users(id) on delete cascade,
  stream_id uuid not null references public.streams(id) on delete cascade,
  title text not null default '',
  prize text not null default '',
  wish text not null default '',
  -- Картинка из зашитого набора, по id: 'h01'…'h20', 'o01'…'o24'.
  image text,
  sort integer not null default 0,
  -- Когда шаг закрыт. Пусто — не закрыт.
  done_on date,
  created_at timestamptz not null default now()
);
alter table public.stream_steps enable row level security;
drop policy if exists "own steps" on public.stream_steps;
create policy "own steps" on public.stream_steps
  for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
```

Комментарии в миграции — по-английски и про «почему», как в 003–009. Пока
миграция не накатана, приложение грузится: таблицы нет — шагов нет (тот же
приём, что у 009).

**Тип.** `StreamStep` в `src/lib/learning/types.ts`: поля таблицы. `done` —
производное: `done_on !== null`.

**Хранилище.** В `LearningStore` — `addStep`, `updateStep`, `deleteStep`, по
одному, как части (`addPart`/`updatePart`/`deletePart`). Перестановка —
`updateStep(id, { sort })` для сдвинутых строк. Обе реализации —
`local.ts` (тот же ключ `readingtracker.learning.v3`, новый массив `steps`)
и `supabase.ts`; перенос на облако при первом входе — `carry.ts` везёт и
шаги. В `LearningContext` — оптимистичные `addStep/updateStep/deleteStep`,
как у частей. Удаление потока каскадом уносит шаги.

**Правила (`src/lib/learning/steps.ts`, с тестами в vitest).**

- Порядок — по `sort`. **Текущий шаг** — первый незакрытый. **Главный приз** —
  последний шаг по порядку; это не флаг, а место: переставили — главным стал
  новый последний.
- Закрытые шаги — всегда префикс: закрыть можно только текущий.
- Перестановка не поднимает шаг выше закрытых; закрытые не двигаются.
- Снять «закрыто» можно только у последнего закрытого (иначе префикс
  рвётся) — см. §5.3. Шаг снова становится текущим; праздника при этом нет.
- Новый шаг добавляется в конец.
- Нет картинки — показывается картинка по умолчанию `o03` (подарок).

## 4. Блок шагов на дашборде

Компонент `StreamSteps` (`src/components/learning/`). Бумага, радиус как у
подложки (22px), тень как у листа. Сетка: слева текст, справа таймлайн
(≈ 0.8fr : 1.6fr). На узком экране (≤ 900px) — столбиком, таймлайн под
текстом.

**Слева.**

- Подпись «Твоя следующая цель» — 13.5px, `--ink-3`. Это просьба Карины;
  правило «без подписи над заголовком» здесь сознательно уступает ей.
- Заголовок — текст текущего шага, 24–30px (`clamp`), 400, трекинг −0.025em.
- Ссылка «Шаги и призы ›» — тихая, пунктиром. Весь левый блок — одна
  кнопка, открывает лист (§5).
- Все шаги закрыты: подпись «Все N шагов позади», заголовок — текст
  последнего шага.

**Справа — таймлайн.**

- Стикеры 68px в ячейках, под каждым подпись шага (12.5px, до двух строк,
  многоточие). Текущий — подпись 500 и чернилами; закрытые — `--ink-2`;
  будущие — `--ink-3`.
- Линия пути по центру стикеров: от предыдущего к этому; пройденный отрезок
  (до текущего включительно) — сплошные чернила 2px, остаток — пунктир
  `--line-2`.
- Влезают все ячейки (по 128px минимум) — путь растягивается на всю ширину,
  ячейки делят её поровну.
- Не влезают — путь прокручивается: горизонтальный скролл со
  `scroll-snap` по ячейкам, без полосы прокрутки; по краям круглые стрелки
  ‹ › (на тач-экране их нет — свайп), шаг стрелки — «видимых минус одна»;
  край гаснет маской с той стороны, где есть ещё, стрелка у глухого края
  тускнеет и выключена. Открывается путь так, чтобы текущий стоял вторым
  слева.
- Текущий отмечен только отгибом и подписью жирнее — без кольца вокруг.
- Кликабельность: закрытый стикер — показать его приз (§6.4 «повтор»);
  текущий — нажатие открывает лист, **потянуть за уголок — отклеить прямо
  здесь** (§6.2); будущие — открыть лист. Увеличения по наведению нет нигде.

**Пустой поток (шагов нет).** Блок тонкой строкой на бумаге: «Разбей цель на
шаги с призами» и `link-btn` «Добавить шаги» — открывает лист сразу в
правке. *Моё решение: пустое состояние не прячет функцию, но и не кричит.*

## 5. Лист «Шаги и призы»

`Sheet` с заголовком «Шаги и призы». Закрытие — только крестик в полосе
сверху (правило листов). Два режима, как у `PartNames` (список и вставка).

### 5.1 Обычный режим

Подзаголовок: «Пройдено N из M · открыто призов: N» / «Все шаги пройдены».

Список с рейкой слева (колонка 52px, рейка 2px по центру): пройденная часть
рейки — чернила, дальше — `--line`.

- **Закрытый шаг.** Вместо галочки — его стикер 48px, чуть вкось (нечётные
  −5°, чётные +4°), как вклеенный. Справа название шага (15.5px/500,
  `--ink-2`) и дата мелко рядом («12 окт»); строкой ниже — приз рукой
  (`--font-hand`, 19px). Нажатие на стикер — показать приз (§6.4).
- **Текущий шаг** раскрыт: номер в лимонном кружке, название 21px/500,
  «Шаг N из M», под ним **купон** (§6.3) со стикером 112px, который
  отклеивают; справа на купоне «Тут приз» рукой (30px) / «Главный приз» у
  последнего, пояснение «Что именно, узнаешь, когда сделаешь шаг. Сделала —
  потяни стикер за уголок.» и `link-btn` «Отметить без стикера». У стикера
  рукописное «тяни» со стрелкой к уголку.
- **Будущий шаг** — номер в кружке и название. Приз не показывается вовсе.
- **Последний шаг**, пока не закрыт, — под названием перламутровый бейдж
  «Главный приз» (без значка). Если он текущий — его купон перламутровый.

Подвал: `link-btn` «Изменить шаги» (значок карандаша) у левого края.

### 5.2 Правка — второй режим того же листа

По образцу `PartNames`: строки правятся на месте, поле пишется на уходе из
него (`onBlur`), кнопки «Сохранить» нет. Подзаголовок: «Призы видны только
здесь, в правке».

Строка: ручка перестановки · номер (у закрытых — галочка) · поля ·
`icon-btn` «Убрать шаг» (`close-md` 15, как у глав).

- Название шага — поле, оформленное как текст (16px/500), без рамки;
  пунктир снизу под курсором, сплошная чернилами в фокусе. Плейсхолдер «Что
  сделать».
- Под ним — приз тем же купоном, каким он будет: стикер 52px (кнопка), поле
  «Приз за этот шаг» рукой 21px, поле «Напутствие, если хочется» 13px. У
  последнего шага купон перламутровый и строка под ним: «Последний шаг —
  главный приз, его билетик перламутровый».
- Нажатие на стикер раскрывает под купоном выбор картинки: `Segmented`
  «Герои / Вещи» и сетка кружков (по 58px, прокрутка внутри, ~3 ряда
  видно). Выбор — сразу пишет и сворачивает. Нет картинки — на месте стикера
  пунктирный круг с плюсом.
- «+ Добавить шаг» — `link-btn` под списком: строка в конец, фокус в её
  название.
- Перестановка: ручка (шесть точек) только у незакрытых. Тянешь — строка
  едет за пальцем с тенью, соседи расступаются на её высоту, выше закрытых
  не поднять; отпустила — пишется новый `sort`. С клавиатуры — стрелки ↑↓ на
  ручке. *Моё решение: на основе `motion` `Reorder` или своими указателями —
  на выбор строителя; поведение — как описано.*
- Подвал: «Готово» — ссылка у левого края, возвращает в обычный режим.
- Поток без шагов открывает лист сразу в правке с одной пустой строкой в
  фокусе (как главы без частей открываются на вставке).

### 5.3 Отменить закрытие

*Моё решение.* В правке у **последнего** закрытого шага рядом с крестиком —
`link-btn` «Не сделано»: снимает `done_on`, шаг снова текущий, рубашка на
стикере возвращается. Остальные закрытые этого не предлагают (§3).

## 6. Стикер, отгиб и праздник

### 6.1 Анатомия стикера — одна на все места

Компонент `Sticker` (`src/components/learning/Sticker.tsx`), props:
`image`, `size`, `state: 'later' | 'next' | 'done'`, `final`.

- **Вырубка** — белый круг, внутренний отступ 5.5% диаметра. Есть всегда, во
  всех состояниях, одной толщины. Тень мягкая, со смещением вниз.
- **Внутри вырубки** — либо картинка (круг, на всю внутреннюю площадь),
  либо рубашка того же круга.
- **Рубашка**: бумага `#fffdf3` со штриховкой под −45° (1.5px через 7px,
  чернила 7%) и по центру рукописный подарок — SVG-контур чернилами одной
  толщины (коробка, лента, бантик; линии чуть неровные, концы круглые),
  62% внутреннего диаметра, чуть вкось. У главного рубашка перламутровая
  (§6.5), подарок — чернилами `#4a3a6e` и с короткими искрами вокруг.
  Пути — из `album-v14.html` (`giftSVG`, вариант «линия»).
- **Отгиб** — только рубашка и только внутри вырубки. Рубашку режет линия
  сгиба; отрезанное отражается поверх — это отогнутый край: бумага с
  градиентом от белого к `#dcdfe1` (у главного — сиреневатый), тень мягкая.
  Отгибается правый верхний угол (там у картинок обычно сама вещь).
- **Параметр отгиба** `--k` — `@property` типа `<length>`, чтобы отгиб
  анимировался. Положение линии в долях внутреннего диаметра: закрыт —
  2.2, «следующий» в покое — 1.12 (под уголком видно почти половину
  картинки), под курсором — 0.96, снят — 0. Реализация в макете: рубашка —
  `clip-path: polygon(...)` от `--k`, край — то же, отражённое
  `matrix(0,-1,-1,0,0,0)` с `transform-origin` на линии, слой рубашки
  повёрнут на −90°, чтобы отгибался правый верхний угол. Перенести
  вычисления как есть (`album-v14.html`, блок «стикер»).
- Состояния: `later` — рубашка целиком; `next` — отогнутый угол; `done` —
  картинка, рубашки нет.

### 6.2 Жест «отклеить»

Один на оба места: купон текущего шага в листе и текущий стикер в
таймлайне.

- Хватается весь стикер (в уголок пальцем не попасть). Курсор `grab` /
  `grabbing`; на точном указателе под курсором угол приподнимается (`--k`
  → 0.96, 220ms ease-out).
- Тянешь — край идёт за указателем по диагонали вниз-влево: `k = k₀ +
  Δ(x − y) / 2`. Назад дальше покоя — с сопротивлением ×0.25.
  `setPointerCapture`, `touch-action: none`.
- Отпустила при `k < 0.62` внутреннего диаметра и сдвиге > 6px — шаг
  закрывается (дотягивается сам, ниже). Иначе угол ложится обратно,
  220ms ease-out.
- Нажала, не сдвинув: в листе — угол подскакивает («сюда»): до 0.82 и
  обратно за 240ms; в таймлайне — открывается лист.
- Enter/пробел на стикере (он `button`) — закрыть сразу. Подпись для
  диктора: «Отметить «…» и открыть приз».
- Когда лист открывается, угол текущего один раз сам приподнимается (через
  0.9с).
- «Отметить без стикера» — то же закрытие без жеста.

**Закрытие.** Рубашка дотягивается до 0 за 420ms
`cubic-bezier(0.77,0,0.175,1)`, отогнутый край улетает влево-вниз с
поворотом и гаснет (260ms, ease-out проекта) → шаг пишется закрытым
(`done_on` = сегодня) → через 140ms открывается праздник.

### 6.3 Купон

Приз — вещь, а не строка, поэтому у него своя подложка: лимонная бумага
`--brand-soft`, радиус 16, волосок `rgba(14,16,18,.08)`, перфорация
пунктиром 1.5px между картинкой и текстом и полукруглые вырубки на её
концах (цвета того, что под купоном). В листе купон горизонтальный, в
празднике — вертикальный (перфорация поперёк). У главного приза купон
перламутровый.

### 6.4 Праздник «Бам!»

Модальное окно поверх всего (фокус, Esc, скролл — как у `Sheet`; строитель
решает, обобщить ли `Sheet` или вынести общую модальность). Тёмная карточка
440px, радиус 26, лимонное свечение сверху, щедрые поля (46/36/36).

Порядок сверху вниз: **возглас** (34px/600) → «✓ » + что сделано (название
шага, 15px; галочка лимонная) → **купон**: стикер 150px, перфорация, название
приза (21px/600), напутствие рукой (20px, `--ink-2`; если пустое — строки
нет) → кнопка «Ура!». Строки «что дальше» в карточке нет.

**Возгласы** чередуются без повтора подряд: «Бам! Ты умничка!», «Вот это
да!», «Так держать!», «Ты огонь!», «Ещё ступенька — твоя!», «Горжусь
тобой!», «Ура-ура!», «Красота, справилась!», «Шаг сделан!», «Ты лучше
всех!». У последнего шага — всегда «Ты дошла до конца!». Нужны английские
пары (§9).

**Хореография** (редкий момент — бюджет на радость здесь):

- подложка 200ms, карточка `translateY(10px) scale(.96)` → на место, 320ms
  ease-out;
- строки проявляются снизу на 10px, шаг 60ms; блок под купоном — с
  задержкой 0.5с;
- стикер «шлёпается» на купон: из `scale(1.3) rotate(−14°)` и прозрачности —
  перелёт до 0.95 и обратно, 560ms; на ударе (~0.22с) купон проседает на
  3px (340ms);
- на ударе от края стикера разлетаются 12 чернильных штрихов (как лучи у
  героев на картинках), 620ms;
- там же из нижних углов экрана — две хлопушки конфетти на `canvas`: по 70
  кусочков, вверх и к центру, гравитация, кувырок, цвета — лимон и маркеры
  палитры (`--mark-pink`, `--mark-sky`, `--mark-mint`, белый); до 4с;
- главный приз: перламутр купона медленно переливается (7с, линейно).

`prefers-reduced-motion`: только проявления по прозрачности; ни шлепка, ни
штрихов, ни хлопушек, ни перелива; отгиб — без анимации.

**После «Ура!».** Следующий шаг входит в кадр, ничего не гаснет: заголовок
блока шагов проявляется из размытия (как придуманная цель в `StreamGoal`,
4px → 0, 260ms), только что открытый стикер в таймлайне подпрыгивает, у
нового текущего через 0.42с один раз приподнимается угол; в листе купон
нового текущего поднимается на 6px (320ms).

**Повтор.** Нажатие на закрытый стикер (таймлайн, лист) открывает ту же
карточку с заголовком «Твой приз» и строкой «название шага · дата», без
штрихов и хлопушек, ничего не меняя.

### 6.5 Перламутр

Токен `--pearl` в `index.css` — один на всё главное: мягкие разводы под
118° (`#fbf3ff → #efe8ff → #e3f3ff → #e6fbef → #fbfbdc → #ffe9f1 → #f6eeff`)
и белый блик сверху слева. Где: вырубка и рубашка последнего стикера, его
купон (лист, правка, праздник), бейдж «Главный приз» (28px, радиус-пилюля,
текст 13/600 `#3a2d57`, без значка). Радужное кольцо вокруг стикера — нет:
читалось кривой обводкой.

## 7. Картинки

Набор зашит в приложение: 20 героев (`h01`–`h20`, жёлтый круг) и 24 вещи

Карины. Подпись картинки для диктора — «Картинка N».

Набор будет пополняться: добавить картинку = положить файл и id в список.
