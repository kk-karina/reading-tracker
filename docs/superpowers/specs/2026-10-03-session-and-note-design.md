# Сессия и мысль: две двери, один Дневник — дизайн

Дата: 2026-10-03. Статус: утверждено, в работе.

В чтении сессия — отдельная запись, к которой привязаны мысли; в обучении
«занятие» — это прогресс плюс не больше одного конспекта, и записанный без
текста прогресс не оставляет во времени никакого следа. Мысль без сессии в
чтении завести можно только в данных: двери к ней нет, правки тоже. Лента
конспектов потока выглядит не так, как Дневник чтения, и фильтра по материалу
в ней нет. Мысли в Дневнике стоят строкой в линейку, конспекты — тихой
бумагой с рамкой, мысли на странице книги — бумагой со спиралью: одна и та же
вещь рисуется тремя способами.

Спека заводит правило подложек, запись занятия в обучении, Дневник потока по
форме Дневника чтения и две разные двери — «Записать сессию / занятие» и
«Добавить мысль / конспект» — с листами, переделанными по принципу композера
(`2026-10-03-unified-add-design.md`): лист выглядит как то, что получится, а
не как анкета.

## 1. Что не так сейчас

| Симптом | Причина в коде |
|---|---|
| Прогресс без конспекта не виден ни в ритме, ни в стрике | `StudySheet` при пустом теле ничего не заводит; `rhythm.ts` и `StreamStats` считают только даты `StudyNote` |
| За занятие можно написать один конспект | `StudySheet` держит одно `body` |
| За занятие можно отметить одну главу | Один `partId` и одна галочка `done` |
| Мысль без сессии не завести и не поправить | Двери нет; в `Journal` у мысли без `session_id` нет «Править» |
| «Записать занятие» и «Добавить конспект» открывают один и тот же лист | `StudySheet` с разным `title` |
| В ленте конспектов нет фильтра по материалу | `Notes.tsx` режет только по тегам |
| Мысль и конспект нарисованы по-разному | `.entry` в `Journal`, `.note-row` в `Notes`, `.thought-card` в `Book` |
| Книга в листе сессии — голый `<select>` | `SessionSheet`, поле `session.book` |

## 2. Правило подложек

**Вещь — на бумаге, событие — на линейке.**

- Вещь — то, что можно взять и открыть: книга (её обложка), материал
  (`.mat-card`), мысль и конспект (бумага `.thought-card`).
- Событие — запись о том, что произошло: сессия и занятие. Строка в линейку
  без фона (`.entry`, `.recent-row`).
- Мысль и конспект рисуются одной бумагой везде — в Дневнике, на странице
  книги, в листе записи. В ленте карточка тихая: без спирали (модификатор
  `.thought-card.flat`), спираль остаётся в галерее мыслей книги.
- `.note-row` удаляется.
- Выдержки на дашборде (`RecentStudyNotes`) остаются типографикой без
  подложки: это цитаты крупным кеглем, а не список вещей.
- Лист конспекта (`.sheet-page`) — та же бумага крупно, не меняется.

Правило записывается комментарием над `.thought-card` в `src/index.css` и
строкой в `CLAUDE.md` (раздел «Пустые состояния» становится «Подложки и
пустые состояния»).

## 3. Данные

### Занятие в обучении

```ts
export interface StudySession {
  id: string
  material_id: string
  date: string // YYYY-MM-DD
  /** Только у книги по страницам. */
  page_from: number | null
  page_to: number | null
  /** Части, отмеченные пройденными в этом занятии. Пусто — не отмечено ни одной. */
  part_ids: string[]
  /** Только у статьи и ролика: «прошла целиком» этим занятием. */
  completed: boolean
  minutes: number | null
  rating: number | null // 1–5, как у сессии чтения
  created_at: string
}
```

- `StudyNote` получает `session_id: string | null`. Старые конспекты остаются
  с `null` — это конспекты без занятия.
- `LearningSnapshot` получает `sessions: StudySession[]`.
- `LearningStore`: `addSession`, `updateSession`, `deleteSession`;
  `NewStudyNote` получает `session_id`.
- Удаление материала уносит его занятия; удаление занятия отвязывает его
  конспекты (`session_id = null`), но не удаляет их — так же, как в чтении.
- Supabase: `supabase/migrations/007_study_sessions.sql` — таблица
  `study_sessions` (`material_id` → `materials` `on delete cascade`,
  `part_ids uuid[] not null default '{}'`, политика «own study sessions»),
  колонка `study_notes.session_id` → `study_sessions` `on delete set null`.
  То же дописывается в `supabase/schema.sql`.
- Локальное хранилище читает старые снимки без `sessions` как пустой список
  (`carry.ts`).

### Арифметика занятия — `src/lib/learning/sessions.ts`

Чистые функции, покрываются тестами до реализации.

- `applySession(material, parts, session)` → заплатки материала и частей:
  страница → `page_current = page_to`; части из `part_ids` → `done = true`;
  `completed` → `status = 'done'`.
- `diffSession(material, parts, before, after)` — то же для правки: части,
  ушедшие из `part_ids`, снова не пройдены; страница меняется, только если
  занятие последнее по дате у этого материала.
- `rollbackSession(material, parts, sessions, session)` — удаление:
  если занятие последнее у материала, `page_current` возвращается к
  `page_from`; его части снова не пройдены; `completed` снимает `done`.
  Удалить занятие — значит откатить его шаг, как в чтении, где прогресс
  считается из сессий.
- `activityDates(sessions, notes)` — даты занятий и конспектов вместе. На
  неё переходят ритм, стрик, «последний раз» (`lastActivity`,
  `lastNoteDate` в `StreamFocus` и `Material`) и `notesByDate` на дашборде.

Статус материала по-прежнему выводится `statusOf`; занятие пишет только то,
из чего он выводится.

## 4. Навигация и Дневник

### Дневник потока

- Вкладка «Конспекты» становится «Дневник»: `nav.journal`, адрес
  `/learning/:slug/journal`; `/notes` перенаправляет туда (`Navigate replace`).
- Страница строится как `src/pages/Journal.tsx`, с тем же устройством:
  `.filter-bar`, слева `Segmented` `Всё / Занятия / Конспекты` и
  `select.sm` материала (появляется, когда материалов больше одного; опции —
  в порядке `sourceOrder`), справа две кнопки.
- Группировка по дням — `buildStudyJournal` в `lib/learning/journal.ts`, с той
  же формой результата, что у `buildJournal` (`days[]` → `date`, итоги дня,
  `items[]`). Обе функции переходят на запись «событие и его вещи»: элемент
  дня — либо событие со списком своих мыслей, либо мысль без события.
  Отдельной функцией, а не обобщением одной: у сессии и занятия разные меры и
  разные ключи, и общая версия свелась бы к набору колбэков.
- Фильтр по тегам у конспектов уходит: в обучении теги не ставит ни один
  лист, и рейка либо пуста, либо из одного тега.

### День — одинаково в обоих разделах

```
3 октября ──────────────────────── +44 стр. · 35 мин · 2 мысли
 +44  [обл] Мастер и Маргарита · 120–164 · 35 мин        Править
        ┌─ ИДЕЯ ─────────────────┐  ┌─ ЦИТАТА ──────────────┐
        │ текст мысли…   стр.164 │  │ …                     │
        └────────────────────────┘  └───────────────────────┘
  ·   [обл] Шум · стр. 40                                 Править
        ┌─ ВОПРОС ───────────────┐
```

- Строка события: в чтении `+N` страниц; в обучении `+N` страниц, `✓ 2`
  (частей) или `✓` (целиком). Дальше обложка, название, подробности, «Править».
- Вещи события лежат под его строкой карточками `.thought-card.flat` в сетке
  по колонке текста (отступ — ширина колонки `.m` плюс промежуток).
- Вещь без события — строка с `·` в колонке меры, обложкой и названием, под
  ней её карточка. «Править» у неё открывает лист мысли (§6).
- Карточка конспекта: заголовок (`noteHeading`, если есть), три строки
  выдержки (`excerptOf`, как в `RecentStudyNotes`), вся карточка — ссылка
  на страницу конспекта с `state.from`.
- Срез «Мысли / Конспекты» показывает и мысли сессий — без строки сессии,
  но с обложкой и названием над карточкой, как у мысли без сессии.

### Материал

Вкладки `Конспекты · Занятия · Части`. «Занятия» — `.recent` с
`.recent-row.with-acts`, как «Сессии» у книги: дата, шаг (`120–164`,
`Глава 3, Глава 4`, `целиком`), минуты и лицо, «Править».

### Слова

«Занятие» и «конспект» в обучении, «сессия» и «мысль» в чтении. Кнопки:
«Записать занятие / сессию», «Добавить конспект / мысль». Лист называется так
же, как кнопка, которая его открыла. Дневник — одно слово в обоих разделах.

## 5. Две двери

| Место | Записать сессию / занятие | Добавить мысль / конспект |
|---|---|---|
| Дневник (оба раздела), полоса | `Jelly.btn` — основная | `Jelly.btn.ghost` — слева от неё |
| Дневник пустой | `btn ghost sm` в `Empty` | `link-btn` рядом |
| Книга | значок в шапке; вкладка «Сессии» | вкладка «Мысли» — кнопка `btn sm` справа от чипов тегов; пустая вкладка |
| Материал | полоса прогресса | вкладка «Конспекты» |
| Дашборд потока | плюс у прогресса фокуса | плюс зоны конспектов |

Сессия — основная: это привычка, ради которой приложение и открывают.

## 6. Листы

Общие детали — в `src/components/log/`:

- `SubjectPick` — шапка листа: обложка, название, автор. Если субъект не
  передан, рядом `⌄`, и по клику под шапкой раскрывается список с маленькими
  обложками (порядок — `pickOrder` в чтении, `sourceOrder` в обучении).
  Смена субъекта пересобирает только то, что от него зависит, — как сейчас.
- `PagesStep` — `120 → [ 164 ]`, `+44 стр.` справа; «от» правится кликом по
  числу; полоса `.meter` показывает было/станет (старая часть сплошная,
  шаг — штриховкой). Фокус в «до». Если «до» меньше «от» — подсказка
  `.error`-цветом под строкой и «Сохранить» гаснет.
- `PartsStep` — крупный ряд `PartDots` в режиме выбора: клик отмечает часть
  пройденной в этом занятии (уже пройденные заливкой и не нажимаются в
  новом занятии; в правке — нажимаются свои). Под рядом — отмеченные части
  строками с полем имени (плейсхолдер — «Глава 4»), под ними
  «Станет 7 из 12». Без частей — `study.noParts`.
- `FlagStep` — один крупный переключатель «Прочитала целиком / Посмотрела».
- `WhenLine` — тихая строка: дата чипом («Сегодня», «Вчера», иначе дата;
  клик раскрывает `input[type=date]`), минуты, лица `FACES`. Всё
  необязательно.
- `DraftStack` — стопка карточек-черновиков `.thought-card.flat` и
  `+ мысль` / `+ конспект` под ней. Новая карточка въезжает (`listItem`) с
  фокусом в тексте; крестик в углу убирает её, на её месте строка «Убрано ·
  Вернуть», пока лист открыт. Сохранённые и убранные удаляются только по
  «Сохранить» — как сейчас в `SessionSheet`.
  - Мысль: `Segmented sm` тегов, `textarea` с подсказкой тега, «стр.» мелким
    моно в углу.
  - Конспект: `NoteEditor`; сверху чип части — одна из отмеченных в занятии
    (по умолчанию последняя), в листе конспекта — любая; «без главы» тоже.
    Контур потока подставляется в первый новый конспект листа.

### Лист сессии / занятия

`SessionSheet` (чтение) и `StudySheet` (обучение):
`SubjectPick` → шаг прогресса по мере → `WhenLine` → `DraftStack` (ноль
карточек по умолчанию) → подвал «Удалить» (в правке) и `[Сохранить]`.

- ⌘↵ сохраняет (`Sheet onSubmit`), `dirty` — когда что-то набрано или
  отмечено.
- Страница мысли по умолчанию — «до» этой сессии; у конспекта — часть.
- Правка: тот же лист с занятием; его мысли/конспекты в стопке. Конспект
  в стопке правки показывается свёрнутым — заголовок и выдержка, «Открыть» —
  правится он на своей странице.
- Удаление спрашивает подтверждение; в обучении текст говорит, что шаг
  прогресса откатится, а конспекты останутся без занятия.

### Лист мысли / конспекта

`ThoughtSheet` (чтение) и `NoteAddSheet` (обучение): `SubjectPick` →
`DraftStack` с одной карточкой и фокусом в тексте → `[Сохранить]`.

- Привязка необязательна: «стр.» пустая; часть — «без главы»; дата
  конспекта — чипом «Сегодня» над стопкой.
- Сохраняется с `session_id = null`.
- `ThoughtSheet` с `note` — правка одной мысли без сессии, с «Удалить».

Старый `StudySheet` с одним конспектом и параметром `title` уходит целиком.

## 7. Движение

Через `/animate` при реализации. Опорные решения:

- Новая карточка в стопке и раскрытие списка `SubjectPick` — `listItem` и
  высота через `layout`, без гашения листа.
- Смена шага прогресса при смене субъекта — подмена в кадре, без перехода
  через пустоту.
- Полоса было/станет едет по ширине `transform: scaleX`, 200 мс `--ease-out`.
- Строки Дневника при смене среза — `layout="position"`, как сейчас.

## 8. Чего не делаем

- Теги у конспектов не ставятся и не фильтруются.
- Минуты в обучении никуда не сводятся — только хранятся и показываются в
  строке занятия.
- Мысль не переносится между сессиями.
- Конспект не правится внутри листа занятия.
