# Reading tracker — дизайн ядра

Дата: 2026-09-13. Статус: утверждён, фаза 5 вынесена в отдельную спеку.

Проект — форк `slap-that-bass` (личный трекер занятий на басу). История того проекта
сохранена в git как справочник; remote удалён.

## 1. Что это

Личный трекер чтения. Не рекомендательный сервис и не социальная сеть — журнал,
который помнит за тебя, что ты прочитала и что из этого вынесла.

Три вещи, ради которых он существует:

1. Видеть книги, которые читаешь параллельно, и прогресс по каждой.
2. Планировать: «прочитано 56 из 234 страниц, это примерно 2 часа из 5».
3. Не забывать прочитанное — мысли фиксируются в момент чтения и легко перечитываются.

## 2. Ключевые решения

| Решение | Основание |
|---|---|
| Сессия привязана к книге | У чтения связь «сессия → книга» естественная, в отличие от практики инструмента, где сессия привязана к категории |
| Записывается страница «до», минуты необязательны | Так реально читают: закрыла книгу, посмотрела номер страницы. Минуты — трение, из-за которого бросают вести журнал |
| Заметки — отдельная сущность, а не поле сессии | За сессию бывает несколько мыслей разной природы. Отдельная таблица даёт фильтр по тегу, поиск, заметки вне сессии и готовое сырьё для рецензий без миграции |
| Тег выбирается первым и меняет подсказку в поле | Рамка для размышления появляется, когда решение писать уже принято, без стены из обязательных полей |
| Ровно одна книга в фокусе | Выражает «главную книгу» объектом, а не списком с радиокнопками. Гарантируется частичным уникальным индексом |
| Поиск через Open Library, ручной ввод — основной путь | Проверено на реальных книгах 2026-09-13: keyless Google Books отдаёт 429 по общей исчерпанной квоте, Open Library отвечает, но не знает ни одного русского издания из пяти проверенных. Поиск остаётся ускорителем для англоязычных книг |
| Обложка рисуется, если картинки нет | Для русских книг бесплатного источника обложек не существует. Восемь книжных тонов, цвет выводится из названия — всегда выглядит намеренно. Поле «ссылка на картинку» рядом, если хочется настоящую |
| Двуязычный интерфейс с самого начала | Копирайт всё равно переписывается целиком; прикручивание локали позже означает трогать каждый файл дважды |
| Роза заменена на «Год в книгах» | Радиальная форма — худшая для сравнения близких величин. Сетка обложек отвечает на главный запрос и растёт вместе с пользователем |

## 3. Модель данных

Три таблицы. `topics` из оригинала исчезает, `songs` становится `books`,
`log_entries` — `sessions`, добавляется `notes`.

```sql
create table books (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null default auth.uid() references auth.users(id) on delete cascade,
  title text not null,
  author text,
  pages integer,
  cover_url text,
  external_id text,
  genre text,
  language text,
  status text not null default 'want'
    check (status in ('want','reading','finished','abandoned')),
  is_focus boolean not null default false,
  rating smallint check (rating between 1 and 5),
  started_at date, finished_at date,
  sort integer not null default 0,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create unique index books_one_focus on books (user_id) where is_focus;

create table sessions (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null default auth.uid() references auth.users(id) on delete cascade,
  book_id uuid not null references books(id) on delete cascade,
  date date not null,
  page_from integer not null,
  page_to integer not null check (page_to >= page_from),
  minutes integer check (minutes > 0),
  rating smallint check (rating between 1 and 5),
  created_at timestamptz not null default now()
);

create table notes (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null default auth.uid() references auth.users(id) on delete cascade,
  book_id uuid not null references books(id) on delete cascade,
  session_id uuid references sessions(id) on delete set null,
  page integer,
  tag text not null check (tag in ('quote','idea','question','disagree','feeling')),
  body text not null,
  created_at timestamptz not null default now()
);
```

RLS по паттерну оригинала: `user_id` заполняется дефолтом `auth.uid()`, политика
`for all using (auth.uid() = user_id) with check (auth.uid() = user_id)` на каждой
таблице. Индекс `sessions (user_id, date desc)`.

**Почему `page_from` хранится, а не выводится.** В интерфейсе оно подставляется из
прошлой сессии и не требует ввода. В базе лежит, потому что при параллельном чтении
неизбежны возвраты к брошенной книге и перечитывание глав; при выводе «текущая минус
предыдущая по порядку» такие случаи дают отрицательные и фантомные дельты. Со
хранимым `page_from` прочитанное — свойство одной строки, не зависящее от правок
истории.

## 4. Производные величины

Не хранятся, считаются на лету — как и в оригинале, где всё выводится из лога.

- **Прогресс книги** — `max(page_to)` по её сессиям против `pages`.
- **Скорость чтения** — страниц в минуту по сессиям, где `minutes` не пуст; общая по
  всем книгам и отдельно по текущей.
- **Затраченное время** — фактические минуты там, где они есть; сессии без минут
  добираются оценкой по средней скорости. В интерфейсе помечается как приблизительное.
- **Остаток** — `(pages - прогресс) / скорость`.
- **Серия** — дни подряд, где есть хотя бы одна сессия, по локальной дате.
- **Застряли** — книги в статусе `reading`, где последняя сессия старше 14 дней.

Эти функции живут в `lib/reading.ts` и покрываются тестами (см. раздел 9).

## 5. Экраны и навигация

Меню: **Прогресс · Полка · Дневник · Настройки**. Хэш-роутинг сохраняется, иначе
GitHub Pages отдаёт 404 на прямой заход.

- **Полка** (`/shelf`) — четыре полки по статусу: читаю, хочу прочитать, прочитано,
  заброшено. Книги стоят обложками, у читаемых снизу прогресс-бар. Форма книги —
  обычные поля; поиск сидит сверху как ускоритель, потому что каталог знает лишь
  часть книг.
- **Книга** (`/book/:id`) — обложка, прогресс, цифры, две ленты: сессии и мысли.
  Мысли фильтруются по тегу. Действия: записать сессию, сделать фокусной, отметить
  прочитанной, забросить. Аналога в оригинале нет, пишется с нуля.
- **Дневник** (`/journal`) — хронология сессий по всем книгам, под каждой её мысли.
  Фильтры по книге и тегу, поиск по тексту. Здесь же добавляется мысль без сессии.
- **Настройки** (`/settings`) — экспорт, импорт, демо-данные, язык, выход.
- **Лист сессии** — не экран, а панель поверх текущего. Книга предвыбрана по
  контексту: с Прогресса — фокусная, со страницы книги — эта, из Дневника —
  последняя активная. Поля: страница «до» (`page_from` показан серым), минуты,
  оценка лицами, мысли с тегами. Когда `page_to` достигает `pages`, предлагает
  отметить книгу прочитанной.

Рецензии отдельным пунктом меню не выносятся: рецензия принадлежит книге, и их
слишком мало, чтобы раздел не выглядел пустым. Место — блок на странице прочитанной
книги.

## 6. Язык интерфейса

Русский и английский, переключатель в шапке и в настройках. В шапке — потому что
язык переключается часто, под язык читаемой книги.

Свой механизм, без библиотеки: контекст локали, хук `useT()`, два словаря. Русский
объявляется первым, из него выводится тип ключей, английский типизируется как запись
с ровно этими ключами — пропущенный перевод роняет `tsc`, а не показывает ключ
пользователю.

Множественные числа — через встроенный `Intl.PluralRules`: в русском три формы
(`one`/`few`/`many`), и записи словаря для считаемых существительных хранят объект с
этими формами, а не строку.

`format.ts` становится зависимым от локали: `fmtMinutes` отдаёт «2 ч 05 мин» или
«2h 05m», `fmtDate` — «Сегодня»/«Вчера» плюс `toLocaleDateString` с текущей локалью
вместо жёсткого `en-GB`. `FACE_LABELS` переезжает в словарь.

Хранится в `localStorage`, начальное значение из языка браузера. Не в базе: это
настройка устройства, и хранение в базе означало бы ожидание сервера до первой
отрисовки. Переводится только интерфейс — заметки, названия и авторы не трогаются.
Язык интерфейса не ограничивает поиск книг.

## 7. Дашборд

- **Герой — полка «читаю сейчас».** Фокусная книга крупно: обложка с тенью,
  корешком и наклоном к курсору (`lean`/`unlean` из оригинального дашборда, связка
  `useMotionValue` + `useSpring`). Рядом метр прогресса и строка «56 из 234 страниц ·
  ≈ 2 ч из ≈ 5 ч · осталось ≈ 3 ч». Остальные читаемые книги стоят корешками; клик
  выдвигает в фокус, клик по большой обложке ведёт на страницу книги.
- **Строка показателей** — за 7 дней (страниц и сессий), серия дней, прочитано за год.
- **Год в книгах** — сетка обложек прочитанного за год, на месте бывшей розы.
- **Доли** — одна горизонтальная полоса с переключателем «жанр / язык». Круговая
  форма не используется: на двух-трёх языках это стат-плитка, нарисованная кругом.
- **Последние мысли** — вместо списка последних записей лога. Дашборд показывает не
  сколько прочитано, а что вынесено.
- **Ритм** — точка на день за 26 недель, величина по страницам (минуты
  необязательны, и половина дней осталась бы пустой).
- **Недели** — страницы по неделям, последние двенадцать.
- **Застряли** — книги в работе без сессий больше двух недель. На месте
  «больше всего практиковал».

Сохраняется характер оригинала: `Pep`, `Wave`, `Counter`, `Burst` на завершении
книги. Уходит звук и пасхалка на слово «slap».

Палитра для жанров прогоняется через валидатор из навыка dataviz до отрисовки, а не
подбирается на глаз.

## 9. Фазы

1. **Каркас.** Локаль и словари, схема, хранилище, типы. Приложение пустое, но
   двуязычное, с входом и работающим локальным режимом.
2. **Книги и полка.** Поиск, добавление, ручной ввод, четыре полки, обложки, фокус,
   страница книги без лога.
3. **Сессии и заметки.** Лист сессии, теги, дневник, вся арифметика.
4. **Дашборд.** Собирается последним, питается всем предыдущим.
5. **Рецензии.** Отдельная спека, после того как первые четыре фазы прожиты в
   реальном использовании: содержание обучения письму должно опираться на настоящие
   заметки, а не на предположения.

**Тесты.** В оригинале их нет вовсе, и для приложения, показывающего списки, это
нормально. Здесь появляется арифметика, которая ломается тихо: дельта страниц при
возврате к брошенной книге, скорость при частично заполненных минутах, серии дней с
учётом часовых поясов. Ставится `vitest`, покрывается только `lib/reading.ts`.
Интерфейс тестами не покрывается.

## 10. Чего здесь намеренно нет

- Таблицы `reviews` и любых обращений к языковой модели — это фаза 5.
- Supabase Storage: обложки живут ссылками. Если ссылки когда-нибудь перестанут
  отдаваться, лечится кэшированием, но закладываться сейчас не нужно.
- Отдельного раздела рецензий в меню.
- Синхронизации языка интерфейса между устройствами.

## 11. Поправки по ходу работы

**2026-09-13, фаза 2.** Google Books заменён на Open Library: проверка на пяти
реальных книгах показала, что keyless-эндпоинт Google отвечает 429 — дневная
квота общая на всех анонимных клиентов. Open Library работает, но из пяти книг
нашла только две англоязычные; три русских издания (Браун, Перель, Вышенков)
отсутствуют. Отсюда два следствия: ручной ввод стал основным путём, а рисованная
обложка — не запасным вариантом, а нормой для русских книг.

**Анимации не отвечают за видимость.** Крупная обложка на странице книги сперва
появлялась через `motion` с начальным `opacity: 0`. В проверке скриншотом она
осталась невидимой — анимация не стартовала. Элемент такого размера не должен
зависеть от того, отработала ли анимация, поэтому наклон стал статическим
трансформом, а появление осталось за общим затуханием страницы.
