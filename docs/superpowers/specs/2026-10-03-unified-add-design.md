# Композер: одно заведение для книги и материала — дизайн

Дата: 2026-10-03. Статус: реализовано. Расхождения с первой редакцией:

- `mergeLinkMeta` не менялся: список заполненных полей — это ключи его патча,
  их считает `useLinkAutofill`.
- В карточке без ссылки нет пустого поля адреса — вместо него `link-btn`
  «Добавить ссылку»; ✦ появляется вместе со ссылкой.
- Подсказка «перетащи или вставь» под обложкой видна, только пока обложки нет.
- Строка меры — не отдельная строка с подписью «Считать по», а фраза под
  автором: число и единица, согласованная с ним («3 главы», «12 лекций»). У
  книги в потоке единица и есть переключатель шкалы: `[страниц | глав]`.
  Сноски «необязательно» нет.
- Действия обложки — значки `.icon-act` с `Tip` (загрузить, по ссылке,
  убрать), как в шапке книги; слов под обложкой нет.
- Подсказки ⌘↵ на кнопке нет; сочетание работает.
- Своя книга как источник (`lib/compose/own.ts`): в захвате по мере ввода, до
  Open Library, показываются свои книги — в потоке с полки и из других
  потоков, на полке из потоков.
- Дубли делятся на два случая (`classifyDuplicates`). Совпадение там же, куда
  заводишь (полка — полка, поток — тот же поток), — запрет: «Добавить» гаснет,
  подсказка красная и ведёт к существующей записи. Совпадение в другом
  разделе — копия: кнопка называется «Продублировать книгу в материалы / на
  полку / в этот поток» и при сохранении забирает из найденного всё, чего нет
  в карточке. Пока вид не выбран руками, название сверяется и у «статьи» по
  умолчанию. Это копия, не связь: прогресс раздельный до проекта «одна книга
  в двух местах».
- Карточка копии показывает то, что сохранится (`withSource`): вид берётся у
  найденной записи, если его не выбирали руками (ссылка на книгу с полки по
  незнакомому домену больше не рисуется «статьёй»), а догадки по ссылке
  уступают своей записи. Дубль показан плашкой во всю ширину над подвалом:
  значок, заголовок, пояснение, «Открыть». При запрете закрытие листа не
  спрашивает — терять нечего.
- Отметки «Уже прочитана / пройдено» в форме нет: прочитанное отмечается
  прогрессом. При правке прежний статус сохраняется.

Книга на полку и материал в поток заводятся двумя разными формами с разной
логикой. `MaterialForm` начинает со ссылки и звёздочки, обложку берёт только
файлом. `BookForm` начинает с поиска по названию в Open Library, ссылки не знает
вовсе, обложку берёт только адресом картинки в голом поле. Обе выглядят как
анкета: колонка подписанных полей, обложка в хвосте маленьким значком,
«Отмена» текстом в шапке.

Спека заводит **одну форму — композер**. Книга на полке в ней не отдельная форма,
а вариант материала вида «книга». Композер начинается с одной строки «ссылка или
название» и раскрывается в карточку, которая выглядит как будущая плитка, а не
как список вопросов.

Следующим проектом идёт «одна книга в двух местах» — слияние `Book` и
`Material`. Здесь оно не делается, но композер к нему готов: форма работает с
черновиком и не знает, в какую сущность он уйдёт (см. §9).

## 1. Что не так сейчас

| Симптом | Причина в коде |
|---|---|
| Два разных первых шага | `BookForm` открывается `.search-box` с поиском Open Library, `MaterialForm` — видом и строкой ссылки со ✦ |
| У книги нет ссылки | В `Book` нет поля `url`; заполнить книгу по странице магазина нельзя |
| Обложка книги — только адрес, материала — только файл | `BookForm` держит голый `<input>` для `cover_url`; `MaterialForm` — `.cover-pick` с `fileToCover` |
| Жанр и язык спрашиваются, но не нужны | Поля в `BookForm`; единственный потребитель жанра, `Shares`, нигде не рендерится |
| По ✦ с магазина приходит мусор в названии | microlink отдаёт `og:title` как есть: «Мастер и Маргарита, Михаил Булгаков – скачать книгу fb2, epub, pdf на ЛитРес» |
| Не видно, что заполнилось | `readLink` молча меняет состояние полей |
| Заполненная форма закрывается молча | `Sheet` закрывается по Esc и клику по подложке без вопросов |
| Разная валидация | В материале «Сохранить» неактивна без названия, в книге всплывает `.error` |
| Сохранить с клавиатуры нельзя | Нет обработки ⌘↵ |
| Нет предупреждения о дубле | Ни одна форма не смотрит, есть ли уже такая книга или ссылка |
| Значки видов врут | Курс — `compass`, но компасом в приложении зовётся поток; видео — `chart-bar` |

## 2. Ключевые решения

**Одна форма, вариант — конфиг.** `Composer` один. `BookForm` и `MaterialForm`
становятся тонкими обёртками: сущность → черновик, вариант, черновик → сущность.
Две формы с общими деталями — тот же разнобой, только в меньшем числе строк.

**Черновик — общий язык.** Форма знает только `Draft`. Куда он уйдёт — в
`books` или `materials` — решает обёртка. Это же делает слияние сущностей
следующим проектом без переписывания формы.

**✦ — явное действие, всегда.** Вставка ссылки ничего не читает сама. Нажатие на
звёздочку — это жест «взмахнуть палочкой», и он остаётся в руках человека; адрес
уходит стороннему сервису только по нему. Enter в строке захвата — то же нажатие.

**Заполняется только пустое.** Правило `mergeLinkMeta` не меняется и
распространяется на полку: набранное руками сильнее любого ответа сети.

**Вид угадывается, но не навязывается.** Догадка по домену выбирает одну из
четырёх кнопок заранее. Тронула вид руками — догадка больше не вмешивается.

**Спрашивается только то, что меряет прогресс.** Жанр и язык уходят из формы
совсем. Колонки в базе остаются: в старых данных они заполнены, терять их незачем.

## 3. Флоу

### Шаг 1 — захват

Лист открывается одной крупной строкой и звёздочкой справа. Фокус в строке.

- Плейсхолдер: «Ссылка или название».
- Под строкой: подсказка (что умеет ✦) и `link-btn` «Заполнить вручную».

По ✦ или Enter строка классифицируется (`looksLikeUrl`, §6):

| Ввод | Что происходит |
|---|---|
| Ссылка | `url` = ввод. Сразу `localMeta` (домен, вид, превью YouTube), лист раскрывается в карточку; поверх приходит `fetchLinkMeta`, пропущенный через `cleanTitle` |
| Текст | Поиск Open Library (`searchBooks`) в **обоих** вариантах. Под строкой — кандидаты с маленькими обложками; последняя строка — «Создать «X» без поиска» |
| Кандидат выбран | Карточка: название, автор, обложка, страницы, `external_id`; вид → «книга», шкала → «страницами» |
| «Без поиска» | Карточка с `title` = ввод |
| «Заполнить вручную» | Пустая карточка |

Пока идёт поиск или чтение, ✦ крутится (`material.fetching`), строка доступна:
новый ввод отменяет прежний запрос (`AbortController`, как сейчас в `readLink`).
Ничего не нашлось — строка `search.none` / `material.fetchNothing` под полем, путь
«без поиска» остаётся.

### Шаг 2 — карточка

```
┌──────────────────────────────────────────────┐
│ litres.ru ✦                              ✕   │  ← строка источника
│ [📖 Книга] [📄 Статья] [▶ Курс] [⏵ Видео]    │  ← вид (только в потоке)
│ ┌────────┐  Мастер и Маргарита               │  ← название, display
│ │        │  Михаил Булгаков                  │  ← автор
│ │ 3 : 4  │  уже в потоке «Дизайн» · открыть  │  ← дубль
│ └────────┘                                   │
│ файл · адрес · ⌘V                            │  ← CoverPicker
│ ───────────────────────────────────────────  │
│ Мерить  [страницами] главами        480      │  ← строка меры
│ ───────────────────────────────────────────  │
│ ○ Уже прочитана        Удалить  [Добавить ⌘↵]│
└──────────────────────────────────────────────┘
```

- **Строка источника.** Домен ссылки и ✦ — повторное чтение. По клику
  разворачивается в поле адреса. Без ссылки — `link-btn` «Добавить ссылку».
- **Вид.** `Segmented` с иконками, четыре кнопки. Смена вида перестраивает
  карточку на месте: кадр обложки, строка меры, подпись «уже …». На полке
  переключателя нет — вид зафиксирован.
- **Название и автор.** Поля, оформленные как текст карточки: название шрифтом
  `display`, автор — обычным. Подписей над ними нет, плейсхолдеры называют поле.
  Рамка появляется по фокусу и при наведении.
- **Дубль.** Строка под автором, сохранять не мешает (§6).
- **Обложка.** `CoverPicker` (§5) слева, в кадре своего вида.
- **Строка меры** — одна строка, содержимое по виду:

  | Вид | Полка | Поток |
  |---|---|---|
  | книга | число страниц | `[страницами \| главами]` + число |
  | курс | — | число лекций, подсказка `material.partsHint` |
  | статья, видео | — | строки нет |

- **«Уже …»** по виду: книга — «Уже прочитана», статья — «Уже прочитана»,
  курс — «Уже пройден», видео — «Уже просмотрено».
- **Низ.** «Удалить» — только в правке, в обоих вариантах (у книги сейчас
  удаление живёт только на её странице; со страницы оно не уходит). «Добавить»
  при заведении, «Сохранить» при правке; неактивна без названия; ⌘↵.

**Правка** открывает сразу карточку, шаг 1 пропускается.

## 4. Варианты

```ts
interface ComposerVariant {
  /** Какие виды можно выбрать. Один — переключатель не рисуется. */
  kinds: readonly MaterialKind[]
  /** Какие шкалы у книги. Одна — переключатель не рисуется. */
  scales: readonly BookScale[]
}
```

| | Поток (`MaterialForm`) | Полка (`BookForm`) |
|---|---|---|
| `kinds` | `KINDS` | `['book']` |
| `scales` | `BOOK_SCALES` | `['pages']` — сессии полки считают страницы |
| сохранение | `addMaterial` / `updateMaterial` + `planParts` с подтверждением `part.confirmDrop` | `addBook` / `updateBook` + `statusPatch` |
| удаление | `deleteMaterial`, `material.confirmDelete` | `deleteBook`, `book.confirmDelete`, переход на полку |

Обёртка передаёт в композер `initial: Draft`, `variant`, `onSave(draft)`,
`onDelete?`. Состояние формы целиком в композере.

Тесты переезжают вместе с файлами. Импорты (`MaterialCover`, `MaterialRow` и
прочие потребители `sourceName`/`sourceOf`) обновляются.

### `CoverPicker`

- Кадр по виду — `KIND_AR` из `MaterialCover`; пустой кадр рисует нарисованную
  обложку того же вида (тон по названию, значок вида), чтобы карточка не
  выглядела дырой.
- Файл: `fileToCover(file, kind)`. У книги на полке — кадр 3:4, тот же 400×533.
- Адрес: `link-btn` «По ссылке» разворачивает поле адреса картинки; адрес
  хранится как адрес.
- Перетаскивание файла на кадр.
- ⌘V, пока лист открыт и фокус не в текстовом поле: картинка из буфера → файл;
  строка-адрес картинки → адрес.
- «Убрать».
- Ошибки — существующие `material.coverBadType` / `coverTooBig` / `coverBroken`.
- Сменился вид после загрузки файла — файл не перекадрируется (исходника уже
  нет); кадр обрезает его через `object-fit: cover`.

### `Segmented` с иконками

`options` получает необязательный `icon?: IconName`. Меняется в
`src/components/ui.tsx` для всех. Иконки видов из того же набора coolicons:
книга `book`, статья `file-document`, курс `monitor-play`, видео `play-circle`.
`KIND_ICON` в `MaterialCover` переходит на них же — один вид, один значок везде.

### `Sheet`

Меняется для всех листов:

- Крестик (`icon-btn`, `aria-label` = `form.cancel`) вместо текстовой «Отмены».
- `dirty?: boolean`. Если `true`, Esc и клик по подложке не закрывают лист: лист
  вздрагивает, в шапке появляется «Не сохранено · закрыть всё равно»
  (`link-btn`). Крестик закрывает так же — через подтверждение в шапке.
- `onSubmit?: () => void` — ⌘↵ / Ctrl+↵ внутри листа.

Композер считает `dirty`, сравнивая черновик с начальным.

## 6. Чистые функции (тесты — до реализации)

**`looksLikeUrl(s)`.** `true` для `https://…`, `http://…`, `youtu.be/x`,
`litres.ru/book/…`, `www.x.com`. `false` для «Мастер и Маргарита»,
«Clean Code», «Ф. М. Достоевский», строк с пробелами.

**`cleanTitle(title, host) → { title, author? }`.**
- Хвост после ` | `, ` – `, ` — `, если в нём слово магазина или действия:
  купить, читать, скачать, отзывы, ЛитРес/litres, Ozon, Goodreads, Amazon,
  «Читай-город», MyBook, Bookmate.
- ЛитРес: «Название, Имя Фамилия – скачать…» → название и автор.
- Goodreads: «Title by Author | Goodreads» → название и автор.
- Amazon: «Title: Subtitle: Author: 9780…: Amazon.com: Books» → название с
  подзаголовком, автор.
- Незнакомое не трогается: лучше длинное название, чем отрезанное.
- Автор из `cleanTitle` идёт в `author` по общему правилу «только пустое».

**`normalizeUrl(s)`.** Без схемы, `www.`, `#…`, `utm_*`/`ref`/`fbclid`,
завершающего `/`; домен в нижнем регистре; путь как есть.

**`normalizeTitle(s)`.** Нижний регистр, ё → е, без пунктуации и кавычек,
пробелы схлопнуты.

**`findDuplicates(draft, { books, materials, streams }, selfId?)`.** Возвращает
до двух совпадений `{ where: 'shelf' | 'stream', id, label, href }`, себя не
считает.
- Книга полки совпадает при равных `external_id`, или `normalizeUrl(url)`, или
  `normalizeTitle(title)` и автора (если автор есть у обоих; иначе — по
  названию).
- Материал совпадает при равном `normalizeUrl(url)`; материал вида «книга» —
  ещё и по названию с автором, как выше.
- Проверяются оба раздела из любого варианта. Подпись: «Уже на полке · открыть»,
  «Уже в потоке «Дизайн» · открыть». `href` открывает в той же вкладке после
  закрытия листа.

**Переводы черновика.** `bookToDraft ∘ draftToBook` и `materialToDraft ∘
draftToMaterial` сохраняют поля; `draftToBook` не пишет `genre` и `language`
(при правке старые значения не затираются, при заведении — `null`);
`draftToMaterial` обнуляет `pages_total` и `page_current` не у книги-страницами,
как сейчас в `MaterialForm.save`.

**`mergeLinkMeta`** — существующие тесты плюс: возвращает список заполненных
полей; без `kind` в черновике полки вид не трогается.

## 7. Данные

- `Book.url: string | null`; `NewBook` получает `url`, `genre` и `language` из
  `NewBook` не уходят (стор их принимает, форма шлёт `null`).
- Локальный стор: старые снимки без `url` читаются как `null`.
- Supabase: `supabase/migrations/006_book_url.sql` —
  `alter table public.books add column if not exists url text;` и та же строка
  в `schema.sql`.
- Страница книги: домен ссылки под автором, ссылкой наружу — как у материала.
- `Shares` и ключи `form.genre`, `form.language`, `shares.*` удаляются.
  `sharesBy` в `reading.ts` — тоже, если больше никем не используется.
- i18n: новые ключи в `dict.ts` (общие для композера) рядом с ru/en;
  `search.*` переиспользуются.

## 8. Движение

Делается через `/animate`; здесь — намерение.

- **Захват → карточка.** Строка захвата не исчезает, а перетекает в строку
  источника (общий `layoutId`); лист растёт по высоте пружиной `Sheet`. Поля
  карточки проявляются лесенкой (opacity + y 6px, шаг ~40 мс). Без `key`-смены
  и без затемнения содержимого.
- **Пришло по ссылке.** Заполненные поля коротко вспыхивают лимонной подложкой и
  гаснут за ~0,9 с. Пришедшая обложка проявляется поверх нарисованной.
- **Смена вида.** Кадр обложки меняет пропорцию раскладкой (`layout`), строка
  меры меняет содержимое с коротким кросс-фейдом высоты.
- **Кандидаты Open Library.** Появляются лесенкой; выбранный «взлетает» в
  карточку — его обложка становится обложкой карточки.
- **Закрытие заполненной формы.** Вздрагивание листа по оси x, ~280 мс.
- **`prefers-reduced-motion`.** Без лесенки, вздрагивания и перетекания;
  подсветка пришедших полей остаётся статичным тоном, который гаснет без
  движения.

## 9. Вне этой спеки

- **Одна книга в двух местах** (слияние `Book` и `Material`, единый прогресс,
  сессии и заметки) — следующий проект, свой брейншторм и своя спека. Главный
  вопрос там — чей прогресс: сессии полки или страница и главы материала.
  Подсказка о дубле между разделами из §6 — мост до него.
- Чтение по вставке без ✦ — отказ по решению, не отложено.
- Свой бэкенд вместо microlink, загрузка внешних обложек к себе.
- Главы у книги на полке.
