# Глава наполовину — дизайн

Дата: 2026-10-04. Статус: согласовано, к реализации.

Модуль курса или главу прошла до середины — это тоже шаг, и записать его
сейчас нечем: точка либо пустая, либо залита.

## 1. Что уже есть

Третье состояние у точки уже нарисовано: «начата» — точка с серым ядром
(`.dot.started`, `partState`). Но оно только производное: конспект к главе
есть, отметки нет. Руками его не поставить, и в занятии оно не остаётся.

## 2. Решения

**Не новое состояние, а «начата» руками.** Картинка та же — ядро в точке,
слово то же — «начата». Новое только то, что его можно поставить самой.

**Жест — цикл кликами.** Клик: пусто → начата → пройдена → пусто. Два быстрых
клика ведут себя как двойной, но без таймера, который отличал бы двойной
клик от одиночного и задерживал каждый одиночный на четверть секунды; на
телефоне двойное касание к тому же увеличивает страницу. Клавиатура ходит
по тому же циклу.

**Счёт — только целые.** «5 из 30», полоса, проценты, дашборд считают
пройденное целиком. Половинка видна точкой и в журнале занятий; день с ней
идёт в ритм и стрик, как любое занятие.

## 3. Данные — миграция 009

```sql
alter table public.material_parts
  add column if not exists started boolean not null default false;
alter table public.study_sessions
  add column if not exists started_ids uuid[] not null default '{}';
```

- `MaterialPart.started` — начата руками. Состояние части: `done` →
  «пройдена», иначе `started` или конспект к ней → «начата», иначе пусто.
  Отметка «пройдена» флаг `started` не снимает: откат пройденной возвращает
  её начатой — какой она и была.
- `StudySession.started_ids` — части, которые занятие оставило начатыми.
  Рядом с `part_ids` и по тем же правилам: удаление занятия откатывает и их.
- До запуска миграции приложение грузится: пустые поля читаются как
  `false` / `[]`, занятие без начатых пишется без ключа.

## 4. Арифметика — `src/lib/learning/sessions.ts`, `parts.ts`

- `nextPartState(state)` — шаг цикла: `fresh → started → done → fresh`.
- `SessionEffects.parts` несёт `{ id, done?, started? }`.
  - `applySession`: `part_ids` → `done: true`, `started_ids` → `started: true`.
  - `diffSession`: снятые из `started_ids` → `started: false`, добавленные →
    `true`; `part_ids` как сейчас.
  - `rollbackSession`: `started_ids` → `started: false`.
- `markPart` (точка на странице материала) принимает целевое состояние:
  - → начата: `started` у части, часть в `started_ids` сегодняшнего занятия;
  - → пройдена: как сейчас, плюс часть уходит из `started_ids`
    сегодняшнего занятия, если была там (начала и закончила в один день —
    это одно «пройдена»);
  - → пусто: снимаются оба флага; из занятия — как сейчас.
- `hollow` считает `started_ids` шагом: занятие с одной половинкой не пустое.
- Удалённая часть уходит и из `started_ids` (`rules.removePart`,
  `updateMaterial` при смене вида).

## 5. Экран

**Ряд точек** (`PartDots`) — без новых картинок: `aria-pressed` становится
`mixed` у начатой. Подсказка диктору — «начата», как и сейчас.

**Лист занятия** (`PartsStep`). У каждой части своя отметка этого занятия:
нет / наполовину / целиком. Клик идёт по циклу; часть, начатая раньше, сразу
идёт к «пройдена» и обратно к «начата». Строки под точками — все отмеченные
в порядке отметки: у пройденной ✓, у начатой ½, у обеих поле имени. Конспект
занятия можно привязать и к начатой. «Станет 5 из 30» — по целым.

**Журнал** (`useStudyLine`): подробность перечисляет пройденные, затем
начатые со словом «наполовину». Шаг крупно — число пройденных; если
пройденных нет, а начатые есть — «½» и «лекции» / «главы». Полоска точек
(`PartsStrip`) рисует начатую ядром, как большая точка.

## 6. Движение

Ядро уже растёт из центра (`.dot-fill`, `transform: scale`): «начата» —
до 0.56, «пройдена» — до 1. Цикл получает это даром, нового не нужно.

## 8. Чего не делаем

- Доли кроме половины (треть, проценты главы).
- Половинка в счёте «N из M», полосе и процентах.
- Двойной клик как отдельное событие.
