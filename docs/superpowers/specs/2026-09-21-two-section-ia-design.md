# Два раздела — дизайн информационной архитектуры

Дата: 2026-09-21. Статус: на утверждении.

Приложение перестраивается из плоского меню в дерево с двумя корнями: **Чтение** и
**Лернинг Хаб**. Содержимое экранов не переписывается — меняются адреса, вложенность
и то, чем человек понимает, где он находится и как вернуться.

Спека опирается на `2026-09-20-learning-hub-design.md`: потоки, бэклог и статусы там
уже спроектированы как горизонт. Здесь горизонт становится навигацией — но **без
сессий, ритма, напоминаний и захвата**. Они встают в это дерево позже и ничего в нём
не ломают.

## 1. Что не так сейчас

Меню плоское и перечисляет пять равноправных пунктов: `Прогресс · Полка · Дневник ·
Обучение · Настройки`. Из них четыре про чтение и один — целый второй продукт,
свёрнутый в одну страницу с табами категорий.

Отсюда три следствия:

| Симптом | Причина |
|---|---|
| Обучение не растёт | Дашборд, бэклог и заметки потока некуда положить: пунктов в меню больше нет, пятый уже не влез на телефон (коммит `a35e007`) |
| Непонятно, где ты | Между `Прогресс` и `Обучение` нет уровня, который сказал бы, что это разные миры. Переход между ними выглядит как переход между Полкой и Дневником |
| Назад некуда | Крошка есть только у книги и материала, и ведёт всегда в одно место. Уровней три, а выражен один |

## 2. Дерево

```
Чтение  |  Лернинг Хаб                                        ⚙  РУ|EN

/reading                   Дашборд чтения        (нынешний Прогресс)
/reading/shelf             Полка
/reading/journal           Дневник
/reading/book/:id          Книга

/learning                  Витрина потоков
/learning/:slug            Дашборд потока
/learning/:slug/active     Изучаю
/learning/:slug/backlog    Бэклог
/learning/:slug/notes      Заметки
/learning/:slug/m/:id      Материал
/learning/:slug/n/:id      Конспект

/settings                  Настройки
```

Симметрия разделов намеренная — это одна и та же работа над двумя разными вещами:

| Чтение | Лернинг Хаб | Роль уровня |
|---|---|---|
| Дашборд — фокус-книга, где я сейчас | Дашборд потока — фокус, цель, сводка | сводка |
| Полка → «Читаю» | **Изучаю** | работа в процессе |
| Полка → «Хочу прочитать» | **Бэклог** | очередь решений |
| Полка → «Прочитано / Заброшено» | Бэклог → вкладка «Архив» | прошлое |
| Дневник | **Заметки** | что осталось в голове |
| Книга | Материал | объект |
| — | Конспект | часть объекта |

Дашборд и «Изучаю» перекрываются, и это не дубль: Прогресс показывает фокус-книгу,
Полка показывает все «Читаю», и никто не жаловался. Дашборд отвечает на «как дела»,
«Изучаю» — на «за что сесть».

Разница глубины между разделами тоже намеренная. В чтении книга это лист: у неё нет
подразделов. В обучении поток — сам по себе рабочее пространство, поэтому уровней на
один больше. Выравнивать их искусственно значило бы завести у книги пустые вкладки.

## 3. Механика навигации

Четыре уровня, и каждый заявлен отдельным элементом.

| Уровень | Первая полоса | Вторая полоса |
|---|---|---|
| 1 — раздел | `Чтение · Лернинг Хаб`, справа `⚙` и язык | — |
| 2 — подраздел | то же | `Дашборд · Полка · Дневник` |
| 2 — поток | то же | `← Лернинг Хаб` · `Имя потока ▾`, под ними `Дашборд · Изучаю · Бэклог · Заметки` |
| 3 — объект | то же | сменяется крошкой |
| 4 — конспект | то же | крошка |

```
Уровень 2, поток                     Уровень 3, материал
─────────────────────────────        ─────────────────────────────
Чтение | Лернинг Хаб        ⚙        Чтение | Лернинг Хаб        ⚙
─────────────────────────────        ─────────────────────────────
← Лернинг Хаб                        ← Professional Growth / Бэклог
Professional Growth ▾
Дашборд·Изучаю·Бэклог·Заметки        Product Design Psychology
```

Имя потока стоит в заголовке, а не в полосе, по той же причине, по которой не влез
пятый пункт меню: четыре подраздела плюс имя потока на ширине телефона не помещаются.
Переключатель `▾` на имени открывает список потоков — тот же переход, что клик по
карточке на витрине, но без возврата на уровень выше.

Крошка на третьем уровне ведёт **туда, откуда пришли**, а не всегда в одно место:
материал открывается и из «Изучаю», и из Бэклога, и из дашборда. Источник берётся из
`location.state`; если его нет — прямой заход по ссылке, перезагрузка — крошка ведёт на
дашборд потока. Так же и у книги: сейчас она всегда ведёт на Полку, хотя приходят на
неё чаще с Прогресса.

Витрина потоков — единственный экран без второй полосы: она там и есть содержимое.

`/settings` живёт вне разделов, иконкой справа в первой полосе. Третий равноправный
пункт спорил бы с утверждением «разделов два».

## 4. Старые адреса

Роуты хэшевые и уже разошлись по закладкам. Все старые адреса остаются и редиректят:

| Старый | Новый | Как |
|---|---|---|
| `/` | `/reading` | `Navigate replace` |
| `/shelf` | `/reading/shelf` | `Navigate replace` |
| `/journal` | `/reading/journal` | `Navigate replace` |
| `/book/:id` | `/reading/book/:id` | `Navigate replace`, id переносится |
| `/learning/m/:id` | `/learning/:slug/m/:id` | slug ищется по `stream_id` материала |
| `/learning/n/:id` | `/learning/:slug/n/:id` | через материал конспекта |

Неизвестный slug, несуществующий материал или конспект — `Navigate replace` на
`/learning`, без экрана ошибки. Промахнуться можно только устаревшей ссылкой, и
витрина отвечает на это лучше, чем слово «не найдено».

## 5. Модель данных

Меняются три вещи. Материалы и конспекты не трогаются, кроме переименования одного
поля и одного нового статуса.

### 5.1 Категория становится потоком

```ts
export interface Stream {
  id: string
  /** Адрес. Рождается из имени и при переименовании не меняется — иначе ломаются ссылки. */
  slug: string
  name: string
  icon: IconName
  accent: Accent | null
  /** Зачем этот поток. Показывается под именем на дашборде. */
  goal: string | null
  /** За что сесть сейчас. Указатель на материал, а не флаг на нём: фокус у каждого потока свой. */
  focus_material_id: string | null
  outline: string | null
  sort: number
  archived: boolean
  created_at: string
  updated_at: string
}
```

`Material.category_id` → `Material.stream_id`. Больше в материале ничего не меняется.

Фокус устроен иначе, чем у книги (`Book.is_focus` — булев флаг на самой книге).
Причина: фокус чтения один на всё приложение, фокус обучения — один **на поток**, и
флаг на материале потребовал бы при каждой смене обходить соседей по потоку. Указатель
на стороне потока делает это одним присваиванием и не даёт завести два фокуса.

Целостность указателя держит хранилище: `deleteMaterial` и перенос материала в другой
поток сбрасывают `focus_material_id` в `null`, если указывал на него.

### 5.2 Slug

```
Professional Growth  →  professional-growth
Английский           →  angliyskiy
🎸                   →  stream-3        (порядковый номер, когда транслитерация пуста)
Driving (ещё раз)    →  driving-2       (столкновение)
```

Правила: нижний регистр, транслитерация кириллицы, всё прочее в `-`, повторы схлопнуть,
края обрезать. Пусто — `stream-<n>` по числу существующих потоков. Столкновение — суффикс
`-2`, `-3`.

Slug выдаётся один раз при создании. Переименование потока меняет `name` и не трогает
`slug` — правило перенесено из спеки Learning Hub, §4.

### 5.3 Статус материала

К пяти существующим добавляется `someday`:

```ts
type MaterialStatus = 'inbox' | 'active' | 'someday' | 'reference' | 'done' | 'dropped'
```

Раскладка по экранам:

| Экран | Статусы | Ярлык |
|---|---|---|
| Изучаю | `active` | «В работе» |
| Бэклог → Входящие | `inbox` | «Входящее» |
| Бэклог → Когда-нибудь | `someday` | «Когда-нибудь» |
| Бэклог → Справка | `reference` | «Справка» |
| Бэклог → Архив | `done`, `dropped` | «Пройдено», «Брошено» |

Без `someday` бэклог схлопывается во «Входящие»: то, что не выкинуть и не взять сейчас,
остаётся висеть непрочитанным, и входящие перестают разбирать совсем. Один член
юниона стоит дешевле, чем неработающая очередь.

Заодно чинится ярлык: `mstatus.dropped` сейчас переведён как «Отложено», что после
появления «Когда-нибудь» начинает врать. Становится «Брошено» / «Dropped».

### 5.4 Миграция хранилища

Ключ `readingtracker.learning.v1` → `readingtracker.learning.v2`. При чтении: если `v2`
нет, а `v1` есть — снимок переносится (`categories` → `streams` со slug, `goal: null`,
`focus_material_id: null`; `category_id` → `stream_id`), пишется в `v2`. Запись `v1`
остаётся нетронутой: пара килобайт против единственной копии конспектов.

`readingtracker.v1` (чтение) не трогается вовсе.

## 6. Экраны

Правило ядра: пустое состояние проектируется наравне с заполненным. Экран со словом
«Скоро» читается не как «данных нет», а как дырка в продукте.

### `/learning` — витрина потоков

```
Лернинг Хаб                                      [ Новый поток ]

┌───────────────────────────┐  ┌───────────────────────────┐
│ ◎ Professional Growth     │  │ ▣ English                 │
│ Product Design Psychology │  │ Фокус не выбран           │
│ 2 из 8 глав               │  │ 5 материалов              │
│ 3 дня назад      3 входя… │  │ вчера                     │
└───────────────────────────┘  └───────────────────────────┘

Архив потоков (2) →
```

Карточка: иконка и акцент потока, имя, материал в фокусе, его прогресс, последняя
активность (самый свежий конспект потока), счётчик входящих. Без фокуса вместо материала
— «Фокус не выбран» и число материалов, чтобы карточка не выглядела сломанной.

Архивированные потоки не показываются; строка «Архив потоков (N)» появляется, только
когда они есть, и раскрывает их тут же, без отдельного экрана.

Пусто: существующий экран раздела без изменений — «Пока ни одного потока», кнопка
«Создать поток» и три подсказки (Professional Growth · Driving · English), которые
заводят поток в один клик.

### `/learning/:slug` — дашборд потока

```
Professional Growth ▾
Вернуть уверенность в профессиональном суждении

┌─ СЕЙЧАС В ФОКУСЕ ──────────────────────────────────┐
│  Product Design Psychology                         │
│  2 из 8 глав · последняя запись 3 дня назад        │
│                                     [ Открыть ]    │
└────────────────────────────────────────────────────┘

ИЗУЧАЮ     1 материал                                     →
БЭКЛОГ     Входящие 3 · Когда-нибудь 4 · Справка 2        →
ЗАМЕТКИ    14 конспектов · последний 3 дня назад          →

Активна 6 недель из 8
```

Цель — редактируемая строка под именем; пустая показывает «Зачем этот поток?» и правится
по клику, без формы.

Блок фокуса — самый крупный элемент после шапки: одна строка, одна кнопка, никакого
выбора. Без фокуса он не пустует, а зовёт: «Выбери, за что сесть» и кнопка в «Изучаю»
(или в Бэклог, если изучать нечего).

Три строки-ссылки ведут в подразделы и несут их числа — дашборд обязан отвечать на
«сколько там», иначе в подраздел приходится заходить, чтобы это узнать.

«Активна N недель из 8» считается по датам конспектов. **Тепловой карты здесь пока
нет**: `Rhythm` в `Charts.tsx` считает страницы из сессий, а сессий в обучении ещё не
существует. Место под неё остаётся; появится вместе с сессиями (спека Learning Hub, §5)
и встанет в ту же строку.

### `/learning/:slug/active` — Изучаю

Карточки, а не строки: здесь выбирают, за что сесть, и для этого нужен прогресс, а не
плотность. Материал в фокусе стоит первым и помечен.

```
┌─ ◎ Product Design Psychology ──────────────── книга ┐
│  ████████░░░░░░░░░░░░░░  2 из 8 глав                │
│  последняя запись 3 дня назад                       │
│                                    [ Продолжить ]   │
└─────────────────────────────────────────────────────┘
```

Действия в карточке: «Сделать фокусом», «Вернуть в бэклог», «Пройдено».

Пусто: «Ничего не изучается. Возьми что-нибудь из бэклога.» и кнопка в Бэклог. Если и
бэклог пуст — «Добавить материал».

### `/learning/:slug/backlog` — Бэклог

Настоящие `tab`/`tabpanel`, как требует правило доступности ядра:

```
[ Входящие 3 ][ Когда-нибудь 4 ][ Справка 2 ][ Архив 6 ]      [ Материал ]
```

Открытая вкладка живёт в адресе — `?tab=someday`, — а не в состоянии компонента.
Просьба была про «чёткую навигацию вперёд назад»: если вкладка не в адресе, «назад»
после трёх переключений уносит со страницы целиком. Фильтр Полки при этом остаётся
локальным и таким же: там это вопрос, заданный странице сейчас, а здесь — место, куда
возвращаются.

Строка — существующая `.mat-row`. Главное действие строки — «Взять в работу»: статус
становится `active`, строка уезжает в «Изучаю», страница остаётся на месте.

Вкладка, которая опустела, пока на ней стоишь, не выкидывает на другую — она показывает
своё пустое состояние. Вкладки с нулём не прячутся: исчезающая вкладка «Входящие»
означала бы, что разбирать больше нечего, а это надо видеть, а не выводить.

### `/learning/:slug/notes` — Заметки

Лента всех конспектов потока по датам, форма Дневника, применённая к обучению: дата,
материал, глава, теги, первые строки. Фильтр по тегу — тот же `Segmented`, что в
Дневнике. Клик ведёт на конспект.

Пусто: «Конспектов пока нет. Глава считается пройденной, когда по ней есть конспект.»

### Материал и конспект

Содержимое обоих экранов не меняется. Меняется адрес, крошка (ведёт туда, откуда
пришли — §3) и одно действие на материале: «Сделать фокусом потока» рядом со статусом,
парное к выбору фокус-книги на странице книги.

Нынешняя `Learning.tsx` — табы категорий и список материалов — расходится целиком:
табы становятся витриной и переключателем `▾`, список материалов — «Изучаю» и Бэклогом.
Отдельной страницы у неё не остаётся.

Настройка потока (имя, иконка, цвет, контур конспекта, удаление) переезжает из табов на
дашборд потока — ссылка «Настроить поток» под целью. Форма `CategoryForm` остаётся той
же, меняет имя на `StreamForm` и получает поле цели.

### Чтение

Экраны не меняются. Меняются адреса, пункт меню `Прогресс` → `Дашборд` и заголовок
страницы `/reading` — на `Чтение`, потому что имя подраздела уже стоит во второй полосе
и повторять его в `h1` незачем. Так же `/learning` получает `h1` «Лернинг Хаб».

## 7. Словарь

Новые ключи: `nav.reading`, `nav.hub`, `nav.dashboard`, `nav.studying`, `nav.backlog`,
`nav.notes`, `hub.*` (витрина), `stream.*` (бывшие `category.*`), `studying.*`,
`backlog.*`, `mstatus.someday`, `crumb.back`.

Переименования: `nav.progress` → `nav.dashboard`; `nav.learning` → `nav.hub`;
`learning.*` → `hub.*`; `category.*` → `stream.*`; значение `mstatus.dropped` в ru.

«Лернинг Хаб» в русском остаётся транслитерацией, а не переводится «Обучением»: это
имя раздела, которым его называет владелец продукта, и оно отличает второй мир от
первого сильнее, чем нейтральное слово.

## 8. Решения и почему так

| Решение | Почему |
|---|---|
| Разделов ровно два, настройки вне их | Третий равноправный пункт разрушает утверждение «два мира». Настройки — инструмент, а не место |
| `/` ведёт на `/reading` | Чтение открывают каждый день; выбор из двух дверей на старте — лишний клик каждый раз ради редкого случая |
| У хаба нет глобального дашборда | Дашборд на каждый стрим — то, что нужно. Глобальный завёл бы второй дашборд, спорящий за роль домашней страницы (риск, записанный в спеке Learning Hub, §11) |
| Изучаю и Бэклог — разные экраны | Бэклог это очередь решений, «Изучаю» — работа. В одном списке очередь перестаёт разбираться |
| Имя потока в заголовке, не в полосе | Четыре подраздела плюс имя на ширине телефона не помещаются — стена, в которую уже упёрся пятый пункт меню |
| Slug не меняется при переименовании | Ссылка на поток должна пережить смену названия |
| `focus_material_id` на потоке, а не флаг на материале | Фокус у каждого потока свой; флаг потребовал бы обходить соседей и допускал бы два фокуса |
| Крошка ведёт по истории, а не в фиксированное место | Материал открывают с трёх экранов; «назад» должно значить назад |
| Старые адреса редиректят, а не ломаются | Роуты хэшевые и уже в закладках |
| Тепловой карты ритма пока нет | Она считает страницы из сессий, которых в обучении нет. Подделка данными о конспектах врала бы о том, что измеряется |

## 9. Чего в этой работе нет

Сессий, листа сессии и вопроса «Что дальше?». Ритма и тепловой карты обучения.
Напоминаний и почты. Захвата и роута `/capture`. «Входящих» как отдельного экрана
поверх статуса. Глобального дашборда обучения. Инсайтов и «Применено». Obsidian,
Supabase, агента. Переноса страниц чтения в `src/pages/reading/`.

Всё это либо горизонт спеки Learning Hub, либо — последнее — отложено сознательно:
`Progress.tsx`, `Shelf.tsx`, `Journal.tsx`, `Charts.tsx` и `index.css` прямо сейчас
содержат незакоммиченную работу над лентой обложек. Переименовывать и двигать файлы
под незавершёнными правками — верный способ их потерять. Страницы чтения остаются на
своих путях; переезд в папку делается отдельным коммитом после того, как лента сядет.

## 10. Проверка

Тестами покрывается только `lib/` — правило ядра, интерфейс проверяется руками.

**Тесты:**

| Что | Где |
|---|---|
| Slug: транслитерация, столкновения, пустой результат, стабильность при переименовании | `lib/learning/slug.test.ts` |
| Миграция `v1` → `v2`: поля, `stream_id`, `v1` остался нетронутым | `lib/learning/store/local.test.ts` |
| `focus_material_id` сбрасывается при удалении и переносе материала | там же |
| Раскладка материалов по экранам (`active` / бэклог / архив) по статусу | `lib/learning/buckets.test.ts` |
| «Активна N недель из 8» по датам конспектов | `lib/learning/rhythm.test.ts` |

**Руками:**

1. Старый адрес `#/shelf` из закладки открывает Полку по новому адресу.
2. `#/learning/m/<id>` попадает на материал внутри своего потока.
3. Переход Чтение → Лернинг Хаб → поток → Бэклог → материал → конспект: на каждом шаге
   видно, где ты, и есть чем вернуться ровно на шаг.
4. Материал, открытый из «Изучаю», крошкой возвращает в «Изучаю»; тот же материал,
   открытый из Бэклога — в Бэклог.
5. Прямой заход по ссылке на материал — крошка ведёт на дашборд потока, не в никуда.
6. Переименование потока не ломает открытую вкладку с его адресом.
7. Ширина телефона: обе полосы читаемы, активный пункт виден, горизонтальной прокрутки
   страницы нет.
8. Первый запуск без потоков; поток без материалов; поток без конспектов — три пустых
   состояния, каждое с одним действием.
9. Переключение языка на каждом уровне дерева.
10. Несуществующий slug уводит на витрину.
